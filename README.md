# Прогресс тренировок

Android-приложение для программ А и Б из приложенных таблиц. Работает без аккаунта и интернета.

## Скачать приложение

[Отладочный APK версии 1.9](downloads/JumpProgramProgression-v1.9-debug.apk): откройте файл в GitHub и нажмите **Download raw file**. Затем откройте APK на Android. Версия 1.9 устанавливается поверх прежних версий с сохранением записей.

## Возможности

- Создание и удаление локальных профилей. При удалении профиля его записи сохраняются в разделе «Записи без профиля» и могут быть назначены другому профилю. Профили из предыдущей версии сохраняются при обновлении.
- Пошаговая запись восьми полей журнала с возможностью прикрепить видео собственного выполнения. Видео можно открыть из записи журнала. Просмотр по профилю и дате, удаление отдельной записи.
- Live-тренировка по программе А или Б: выбор недели 1–4, десять упражнений в порядке таблицы, план повторений и таймер отдыха со звуком.
- Видео каждого упражнения в полноэкранном альбомном режиме без панели перемотки. Общие упражнения используют одни и те же ролики; все видео встроены и доступны без интернета.
- После тренировки можно выбрать одного или нескольких участников и последовательно заполнить для каждого вес, RPE, боль и видео выполнения. Дата, программа, упражнения и повторы заполняются автоматически; фактические подходы и повторы можно исправить, если они отличались от плана.
- Выгрузка Excel `.xls` по выбранному профилю или всем записям за период между двумя датами. Каждое упражнение сохраняется отдельной строкой. Android предложит выбрать папку на телефоне.
- Отчёт для тренера в ZIP за выбранный период: `index.html` с результатами каждого упражнения и вложенные видео. После сохранения появится кнопка «Поделиться ZIP». Тренеру нужно распаковать архив и открыть `index.html` в браузере; видео открываются из отчёта без установки приложения.

Данные программ находятся в `app/src/main/assets/program_a.json` и `program_b.json`. Журнал и профили хранятся в локальной базе SQLite. Прикреплённые видео остаются в памяти телефона: не удаляйте и не перемещайте их до создания ZIP-отчёта. Синхронизации между устройствами и входа по email нет.

## Сборка

Нужны JDK 17 или 21, Android SDK Platform 35 и Build Tools 35.0.0. Задайте `ANDROID_HOME` или `ANDROID_SDK_ROOT`, затем выполните:

```sh
./gradlew :app:testDebugUnitTest :app:assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. Минимальная версия Android — 8.0 (API 26).
