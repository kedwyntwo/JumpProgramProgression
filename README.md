# Прогресс тренировок

Простое Android-приложение на Java для программы A из приложенной таблицы. Работает без аккаунта и сети.

## Возможности

- Пошаговая запись восьми столбцов журнала: дата, тренировка, упражнение, вес, подходы × повторы, RPE, боль/дискомфорт и комментарий. За одну дату можно сохранить несколько упражнений.
- Просмотр записей по дате с полями только для чтения.
- Live-тренировка: выбор недели 1–4, десять упражнений в порядке таблицы, план повторений, фокус техники и таймер отдыха со звуковым сигналом. Для диапазона отдыха таймер использует верхнюю границу.

Данные упражнений взяты из `Программа А.xlsx` и находятся в `app/src/main/assets/program_a.json`. Пустой шаблон `Трекинг.xlsx` определяет поля журнала. Записи сохраняются в локальной базе SQLite на устройстве; файл XLSX не нужен во время работы приложения.

Сейчас приложение содержит программу A. Импорт существующих заполненных таблиц и синхронизация между устройствами не предусмотрены.

## Сборка

Нужны JDK 17 или 21, Android SDK Platform 35 и Build Tools 35.0.0. Задайте `ANDROID_HOME` или `ANDROID_SDK_ROOT`, затем выполните:

```sh
./gradlew :app:assembleDebug
./gradlew :app:testDebugUnitTest
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. Минимальная версия Android — 8.0 (API 26).
