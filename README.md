# Прогресс тренировок

Простое Android-приложение на Java для программы A из приложенной таблицы. Работает без аккаунта и сети.

## Скачать приложение

[Отладочный APK версии 1.3](downloads/JumpProgramProgression-v1.3-debug.apk): откройте файл в GitHub и нажмите **Download raw file** (значок стрелки вниз). Затем откройте скачанный APK на Android. Это тестовая сборка, устанавливаемая вручную; для публикации в магазине нужна отдельная релизная сборка.

## Возможности

- Пошаговая запись восьми столбцов журнала для Кирилла или Игоря: дата, тренировка, упражнение, вес, подходы × повторы, RPE, боль/дискомфорт и комментарий. Для веса есть отдельная кнопка «Свой вес», а подходы и повторы вводятся в два числовых поля.
- Просмотр журнала: сначала выбирается пользователь, затем дата. Записи можно удалить после подтверждения.
- Live-тренировка: выбор недели 1–4, десять упражнений в порядке таблицы, план повторений, фокус техники и таймер отдыха с системным звуком будильника. Для диапазона отдыха таймер использует верхнюю границу. Кнопка «Посмотреть видео упражнения» открывает ролик текущего упражнения с управлением воспроизведением; все десять видео доступны без интернета.
- После Live-тренировки приложение предлагает внести отмеченные упражнения сначала в журнал Кирилла, затем Игоря. Дата, упражнения и повторы заполняются из программы; для каждого остаётся указать вес, RPE и боль.
- Выгрузка настоящего Excel `.xls`: выбираются Кирилл, Игорь или все записи и диапазон между двумя датами включительно. Для каждого упражнения создаётся отдельная строка. Android предложит сохранить файл в выбранную папку телефона.

Данные упражнений взяты из `Программа А.xlsx` и находятся в `app/src/main/assets/program_a.json`. Пустой шаблон `Трекинг.xlsx` определяет поля журнала. Записи сохраняются в локальной базе SQLite на устройстве; файл XLSX не нужен во время работы приложения.

Профили Кирилла и Игоря локальные: входа по email и синхронизации между устройствами пока нет. Старые записи без пользователя доступны отдельно в журнале и могут быть назначены одному из участников. Сейчас приложение содержит программу A; импорт заполненных таблиц не предусмотрен.

## Сборка

Нужны JDK 17 или 21, Android SDK Platform 35 и Build Tools 35.0.0. Задайте `ANDROID_HOME` или `ANDROID_SDK_ROOT`, затем выполните:

```sh
./gradlew :app:assembleDebug
./gradlew :app:testDebugUnitTest
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. Минимальная версия Android — 8.0 (API 26).
