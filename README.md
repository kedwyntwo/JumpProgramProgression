# Прогресс тренировок

Простое Android-приложение на Java для программы A из приложенной таблицы. Работает без аккаунта и сети.

## Скачать приложение

[Отладочный APK версии 1.1](downloads/JumpProgramProgression-v1.1-debug.apk): откройте файл в GitHub и нажмите **Download raw file** (значок стрелки вниз). Затем откройте скачанный APK на Android. Это тестовая сборка, устанавливаемая вручную; для публикации в магазине нужна отдельная релизная сборка.

## Возможности

- Пошаговая запись восьми столбцов журнала: дата, тренировка, упражнение, вес, подходы × повторы, RPE, боль/дискомфорт и комментарий. Для веса есть отдельная кнопка «Свой вес», а подходы и повторы вводятся в два числовых поля.
- Просмотр записей по дате с полями только для чтения и удалением записи после подтверждения.
- Live-тренировка: выбор недели 1–4, десять упражнений в порядке таблицы, план повторений, фокус техники и таймер отдыха с системным звуком будильника. Для диапазона отдыха таймер использует верхнюю границу.
- После Live-тренировки приложение предлагает внести в журнал отмеченные упражнения. Дата, упражнения и повторы заполняются из программы; для каждого остаётся указать вес, RPE и боль.

Данные упражнений взяты из `Программа А.xlsx` и находятся в `app/src/main/assets/program_a.json`. Пустой шаблон `Трекинг.xlsx` определяет поля журнала. Записи сохраняются в локальной базе SQLite на устройстве; файл XLSX не нужен во время работы приложения.

Сейчас приложение содержит программу A. Импорт существующих заполненных таблиц и синхронизация между устройствами не предусмотрены.

## Сборка

Нужны JDK 17 или 21, Android SDK Platform 35 и Build Tools 35.0.0. Задайте `ANDROID_HOME` или `ANDROID_SDK_ROOT`, затем выполните:

```sh
./gradlew :app:assembleDebug
./gradlew :app:testDebugUnitTest
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. Минимальная версия Android — 8.0 (API 26).
